# DELIVERY CHECKLIST（交付清單）

本清單依據《星墜答問：神話機神》規格書第 18 節標準逐條確認。

---

## 遊戲本體
- [x] **可直接開啟的 `starfall-quiz.html`**：主入口檔，單頁式響應式架構，不依賴伺服器端渲染。
- [x] **遊戲核心 `game.js`**：固定 60FPS 時間步迴圈，包含實體、碰撞、彈幕、傷害管線、音效合成與狀態機。
- [x] **UI 樣式 `style.css`**：商業級科幻機甲硬表面風格，所有互動目標均符合 44x44px 以上觸控規範。
- [x] **1–10 關流程可進行**：具備從第 1 關迦樓羅至第 10 關提亞瑪特之完整關卡進程與通關結算。
- [x] **玩家觸控／滑鼠控制**：支援手機單指相對位移拖曳（手指不擋視線）與桌面滑鼠／鍵盤操控。
- [x] **玩家核心碰撞判定**：碰撞半徑約機身 22–24%，機翼裝甲邊緣可穿梭彈幕並觸發擦彈。
- [x] **雜兵、波次、碰撞、傷害**：功能型雜兵、波次計時、擊殺掉落、受傷短暫無敵與護盾抵禦。
- [x] **小 Boss／大 Boss 雙答題流程**：每關「雜兵 -> 小 Boss -> 5 題答題 -> 整備 -> 喘息波 -> 大 Boss -> 5 題答題 -> 整備/融合」完整循環。
- [x] **十位 Boss 資料與初版機制**：10 位神話機神專屬大招預警、語音宣告、二階段變身與極性護盾。
- [x] **武器、品質、Rank、插槽**：14 種武器裝備、Rank 1–5 成長、品質倍率（普通至傳說）與固定插槽結構。
- [x] **靈丸、稜鏡、光束、融合**：
  - 靈丸：獨立右下集氣區、5 階蓄力、粒子電弧、原創語音「靈——丸！」、巨額穿透爆炸與震動。
  - 稜鏡僚機：具備真實折射線段與持續 DPS 傷害，支援多目標連鎖。
  - 光束砲：貫穿能量柱與命中火花。
  - 6 組真融合配方（彗星靈丸、虹晶天幕、蜂群獵手、軌道壁壘、熔核轟擊、凝時裁決）。
- [x] **LAB 面板**：戰鬥中隨時點擊呼叫，具備武器調階、品質切換、Boss 召喚、無敵模式、碰撞框可視化與 DPS 統計。

## 學習與資料
- [x] **題庫 CSV 匯入／匯出**：支援逗號與引號相容之 CSV 解析器，可隨時匯入或下載。
- [x] **`default-question-bank.csv`**：完整內建 150 題國語文優質標準題庫（注音、字形、部件、成語、閱讀理解與記憶口訣）。
- [x] **自適應出題**：依平滑錯誤率 `E = (wrong + 2) / (attempts + 4)` 動態分配 60% 弱點題、25% 間隔複習題、15% 探索新題。
- [x] **錯題複習**：答錯題目進入「錯題復仇」池，再次答對時解鎖翻盤獎勵並扣減知識壓力。
- [x] **IndexedDB 存檔**：使用本機 IndexedDB 持久化保存學生作答歷程、題目熟練度與離線隊列。
- [x] **JSON 備份／還原**：支援將個人進度與題庫資料匯出為 JSON 備份檔。
- [x] **圖鑑**：記錄已遭遇之神話機神與解鎖之真融合配方。
- [x] **家長報表資料結構**：包含總題數、正確率、各單元表現、錯題分佈與作答反應時間等統計欄位。
